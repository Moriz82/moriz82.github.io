Calendar Sync Privacy Policy

How UTSA CyberComp Calendar Sync accesses, uses, stores, and deletes Google user data.

Scope

UTSA CyberComp Calendar Sync is a private local utility for one authorized user. It is not offered as a public service.

Google user data accessed

The utility accesses the approved Google account's OpenID subject identifier and events on calendars the user owns. It uses the identifier only to prevent writing to the wrong account. It reads, creates, and updates only marked calendar copies managed by this utility.

How data is used

Calendar data is used only to mirror the user's UTSA CyberComp Nextcloud events into the user's primary Google Calendar, prevent duplicate copies, preserve all-day dates and recurrence, and audit the resulting Google events. The utility does not create guests, invitations, or Google Meet links.

Storage and retention

The OAuth client credential and refresh token are stored in the owner's macOS Keychain. Short-lived access tokens remain only in process memory. Private local files store managed Google event identifiers, source content digests, and audit timestamps. Event content also exists in the user's Google Calendar copies.

Managed Google copies remain until the user explicitly approves their deletion. Local state and Keychain credentials remain until the owner removes them or uninstalls the utility.

Sharing

Google user data is not sold, rented, used for advertising, or shared with third parties. Data is sent only between the user's local Mac, Google Calendar, and the user's authorized Nextcloud service as required for the requested synchronization.

Security and control

The utility requests the narrow Google Calendar permission for events on calendars the user owns. It creates private events, stores credentials in Keychain, and stops on account mismatches, incomplete source reads, unexpected invitations, missing copies, or destination drift.

The user can revoke Google access from their Google Account permissions, remove the named Keychain credential, or uninstall the local scheduler. Revocation stops future synchronization but does not automatically delete existing Google events.

Contact

Questions about this policy can be sent through the site's contact page.
